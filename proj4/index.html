A.2: Recovering a homography

A homography maps a source point (x, y) to a reference point (u, v). Dividing by the last homogeneous coordinate gives two equations per match. Setting h33 = 1 leaves eight unknowns.

u = (h11 x + h12 y + h13) / (h31 x + h32 y + 1)
v = (h21 x + h22 y + h23) / (h31 x + h32 y + 1)

[ x y 1  0 0 0  -ux -uy ] h = u
[ 0 0 0  x y 1  -vx -vy ] h = v

h = [h11 h12 h13 h21 h22 h23 h31 h32]^T
A has shape (2N, 8); b = [u1 v1 ... uN vN]^T.
h = argmin ||Ah - b||^2

computeH(im1_pts, im2_pts) builds this system and calls NumPy's least-squares solver. Coordinates are first centered and scaled so their mean distance from the origin is sqrt(2). If Hn is the solution in these normalized coordinates, the pixel-coordinate matrix is H = T2-1 Hn T1. Finally, H is divided by its bottom-right entry.

Each panorama uses more than four landmarks. The television landmarks were identified by inspection and locally refined with normalized patch correlation. For the kitchen and bookshelf, SIFT supplied candidate locations that were reviewed and stored as fixed correspondences. Every displayed H is then recovered by the custom least-squares solver. No library homography estimator or perspective warp is used.

A.3: Inverse warping and interpolation

Both warp functions use inverse mapping. First, project the four source corners through H to determine a destination bounding box. Floor the minimum coordinates and ceil the maxima. Negative destination coordinates are preserved through a stored canvas offset.

For each integer destination pixel center, apply H-1 and divide by the resulting homogeneous coordinate. Sample the source only when that coordinate lies inside its valid pixel-center rectangle. A separate Boolean mask distinguishes missing samples from valid black pixels.

[sx sy 1]^T ~ H^-1 [dx dy 1]^T

Nearest: I(round(sx), round(sy))

Bilinear: x0=floor(sx), y0=floor(sy)
          a=sx-x0, b=sy-y0
I(sx,sy) = (1-a)(1-b) I(x0,y0)
         + a(1-b)     I(x0+1,y0)
         + (1-a)b     I(x0,y0+1)
         + ab         I(x0+1,y0+1)

The four bilinear weights sum to one. At the last valid row or column, the neighbor indices clamp to the image boundary. The implementation processes rows in chunks so intermediate coordinate arrays stay small. It uses NumPy arithmetic for both interpolation methods.

For rectification, four selected corners map to the corners of a rectangular target. Only that target is sampled. Unlike panorama fitting, these four exact corner constraints have no redundancy; the assumed rectangle and chosen aspect ratio determine the result.

A.4: Blending into a mosaic

The mosaics split the wide change in viewing direction across an intermediate projection. After normalizing the scale of H, compute a real matrix square root S. Image 1 maps through S and image 2 through S-1, so corresponding points still coincide because S-1H = S. This reduces the stretching produced by forcing the whole panorama into one endpoint view.

The canvas is the union of the transformed corners. The living-room example uses source-border-distance feather weights. For the kitchen and bookshelf, a vertical path through low-disagreement overlap pixels selects the join; the weights transition linearly across 15 pixels on each side of that path. All weights are masked and normalized:

w_i = blend_weight_i * validity_i
M(x,y) = sum_i [w_i(x,y) * I_i(x,y)] / sum_i w_i(x,y)

A pixel belonging to one source retains that source. Pixels outside both footprints are transparent. Feathering reduces brightness boundaries; a narrow seam also limits broad ghosting. Neither operation corrects the scene geometry or removes glare.

No exposure correction or pyramid blending is applied. The comparisons use identical geometry, changing only the compositing weights.

What I learned and sources

The indoor captures show why keeping the camera center fixed matters. Remaining in one standing position does not completely fix the lens position: small handheld shifts produce noticeable parallax for nearby objects. A homography can fit one depth well while leaving other depths misaligned. Spread-out correspondences and the measured residuals make that limitation visible.

Inverse warping gives a defined source lookup for every destination pixel and avoids the holes caused by forward splatting. The mask is just as important as the color array: black image content must remain valid, while empty projective margins must not darken the blend.

The interpolation comparison makes a separate tradeoff visible. Nearest neighbor is fast and preserves hard pixel values; bilinear interpolation uses more work to make subpixel movement look smoother. Blending then addresses another issue, the boundary between already registered images.

B.1: Harris corner detection

Part B replaces saved landmark correspondences with features detected and matched directly from the photographs. The three personal image pairs and the Part A inverse warper and blending methods are reused. The automatic alignment function receives image arrays and scalar settings; it never receives the Part A point pairs.

The detector uses Sobel gradients and a Gaussian integration window with sigma = 1. Following the harmonic Harris response used by the provided sample, the structure tensor and corner score are:

M = Gaussian_sigma=1 * [[Ix^2, Ix Iy], [Ix Iy, Iy^2]]
f = det(M) / (trace(M) + 1e-12)

Candidate corners are positive 3 x 3 local maxima above 0.001 times the image's maximum response. A 20-pixel border is excluded so a 40 x 40 descriptor support fits in the image. This implementation uses one scale and integer feature positions.

Strong responses cluster on detailed objects and high-contrast edges. Spatial suppression preserves more of the room's coverage, which matters when only part of an image overlaps its neighbor. A textureless television screen still supplies few stable features.

B.1: Adaptive non-maximal suppression

For each candidate i, ANMS finds the distance to the nearest candidate whose corner response is significantly stronger. A response within ten percent of the maximum is therefore not suppressed by an almost equal neighbor:

r_i = min_j ||p_i - p_j||, subject to f_i < 0.9 f_j
No qualifying neighbor: r_i = infinity.
Keep the 2,500 largest radii (or all candidates if fewer exist).

Ties are resolved by response strength and then input index. Distances are processed in blocks to avoid storing the full candidate-by-candidate matrix. The figures use 500 selected points for visibility; the actual descriptor and matching runs retain up to 2,500 per image.

B.2: Normalized patch descriptors

Each ANMS corner describes an axis-aligned 40 x 40 grayscale neighborhood. The image is Gaussian blurred with sigma = 2 before sampling an 8 x 8 grid. Sample centers are five pixels apart, at offsets -17.5, -12.5, ..., 17.5; bilinear lookup handles the half-pixel positions. The larger support and blur reduce sensitivity to small localization errors.

d = (patch_8x8 - mean(patch_8x8)) / std(patch_8x8)

The flattened descriptor has 64 values. Flat patches with standard deviation at most 1e-6 are discarded. Bias/gain normalization removes additive brightness and positive contrast changes, but does not remove perspective deformation or reflections.

Across all retained descriptors, maximum absolute mean is 2.28e-14 and maximum deviation from unit standard deviation is 3.33e-16. A numerical test also verifies invariance to a positive affine intensity change.

B.3 / B.4: Matches - Living room and television

For every source descriptor, find its two closest reference descriptors by sum of squared differences (SSD). Retain a match when SSD1 / SSD2 < 0.80, and require that the reference feature also chooses this source as its nearest neighbor. This reciprocal check makes accepted matches one-to-one. An ambiguous zero/zero ratio is rejected.

The threshold is on squared distances, equivalent to an Euclidean distance ratio below sqrt(0.8), approximately 0.894. This permissive threshold preserves candidates in the low-texture scenes; geometric RANSAC then removes most of them. A small absolute SSD alone is unreliable for repetitive patches.

B.4: Robust homography estimation

The four-point RANSAC loop is implemented from scratch. Each trial samples four distinct matched pairs, fits H using the normalized least-squares solver from Part A, and scores all tentative matches. Degenerate samples are rejected by the homography solver.

e_forward  = || project(H, p) - q ||
e_backward = || project(inverse(H), q) - p ||
e_symmetric = sqrt((e_forward^2 + e_backward^2) / 2)
inlier = e_symmetric < 4 pixels

Checking both directions reduces support for nearly collapsed mappings. Models are ranked by inlier count, then median inlier error. The current inlier fraction w updates the sampling bound N = ceil(log(1 - confidence) / log(1 - w^4)), with confidence 0.999, at least 100 trials and at most 500,000. The random seed is 180 for every pair.

After sampling, refit H on the entire winning consensus. Up to ten consensus updates are allowed while the truncated symmetric squared-error cost does not increase. The returned mask is recomputed from the returned matrix. No library homography estimator, feature matcher, perspective warp, or RANSAC routine is used.

Part B: Observations and reproducibility

ANMS, descriptor normalization, ratio matching, and RANSAC address different failure modes. ANMS spreads limited feature capacity across an image; normalization handles brightness and contrast; the ratio test rejects ambiguous appearance; RANSAC rejects matches inconsistent with one homography.

The indoor photographs also expose the model's limits. Low texture reduces the number of useful matches, repeated book and cabinet patterns create ambiguity, and handheld parallax causes different depths to favor different homographies. A low residual on a small consensus should be interpreted alongside the spatial spread of inliers and visible seam quality.

The required B.1-B.4 pipeline is single-scale and axis-aligned. Optional B.5 multiscale, rotation-invariant, and panorama-recognition extensions are not claimed.
