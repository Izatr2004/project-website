# CS 180 Project 0 — Becoming Friends with My Camera

A responsive photo essay for CS 180 Project 0. It presents the portrait and
architectural perspective comparisons, plus a five-frame dolly zoom.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in a browser.

## Project files

- `app/page.tsx` contains the page content.
- `app/globals.css` contains the visual design and print layout.
- `public/images` contains web-ready photographs and the animated GIF.
- `part1`, `part2`, and `part3` preserve the original HEIC photographs.

The page includes print styles so it can be saved as a PDF for submission.
